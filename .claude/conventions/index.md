# Конвенции написания кода

[← Назад](../CLAUDE.md)

Детальные правила, как писать код в проекте AgentOrchestra. Разложены по языкам
и сквозным темам. Общие принципы верхнего уровня — в
[CLAUDE.md](../../CLAUDE.md); эта папка — их детализация и дополнение, не
дубликат.

## Разделы

- [Java](java/index.md) — backend-модули (backend-core, task-tracker,
  agent-manager и др.)
- [TypeScript](typescript/index.md) — frontend-core
- [Shared](shared/index.md) — правила, общие для всех языков (тесты, коммиты,
  обработка ошибок)

## Как пользоваться

1. Определи язык, на котором пишешь в текущем инкременте
2. Прочитай `<язык>/index.md` — список релевантных правил
3. Прочитай только те файлы правил, которые реально относятся к тому, что
   меняешь
4. Правила не дублируют друг друга — каждый файл = одно правило
