# Состав приложения

## Две половины

Приложение — монорепозиторий с двумя независимыми npm-проектами:

- `frontend/` — React + TypeScript + Vite, интерфейс;
- `server/` — Node.js + Express + TypeScript, серверный каркас.

Общего пакета с типами нет: домен реализован только на стороне интерфейса, и общий пакет связал бы
две половины, между которыми ещё нет обмена данными.

## Интерфейс

- `domain/` — чистая доменная логика и типы: правила операций, расчёты отчёта, разбор и
  форматирование денег. Не зависит от React и от хранилища;
- `data/` — интерфейс репозитория, реализация поверх localStorage, стартовый набор категорий;
- `state/` — провайдер приложения, который держит состояние и перечитывает его после каждой
  операции с данными;
- `features/` — экраны: операции, счета, категории, отчёт, настройки;
- `ui/` — переиспользуемые элементы: поля формы с подписью и ошибкой, модальные окна, пустые
  состояния.

Маршрутизация — на клиенте, по экранам; при переходе по неизвестному адресу открывается список
операций.

## Графики и выгрузка

Графики построены библиотекой `recharts`, выгрузка в Excel — библиотекой `xlsx`. CSV собирается
вручную — для него достаточно разделителя и BOM, внешняя зависимость ради трёх секций отчёта
лишняя.

## Сервер

`server/src/routes` — заглушки доменных эндпоинтов, `server/src/services` и
`server/src/repositories` — интерфейсы сервисного и репозиторного слоёв без реализаций,
`server/openapi/openapi.yaml` — контракт.
